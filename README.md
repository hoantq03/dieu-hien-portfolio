# Nguyễn Thị Diệu Hiền Portfolio

Portfolio site inspired by the [Emma J. Webflow template](https://emmajohnson.webflow.io/), customized for Nguyễn Thị Diệu Hiền.

## Stack

- Vite + React + TypeScript
- GSAP for hero / scroll motion

## Run

```bash
npm install
npm run dev
```

## Images

Put your photos in `public/img/` — see `public/img/README.md` for the file map. Replace files with the same names; no code changes needed.

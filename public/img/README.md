# Thư mục ảnh (`public/img`)

Thay file **cùng tên** (giữ đuôi `.webp` / `.jpg` / `.svg` nếu có thể) — không cần sửa code.

## Ảnh chính

| File | Vị trí trên web |
|------|------------------|
| `hero.webp` | Ảnh lớn đầu trang (portrait) |
| `cta-bg.webp` | Nền section “REACH NEW HEIGHTS” |
| `logo.svg` | Logo nav (mobile) |
| `logo-white.svg` | Logo nav (desktop, trên nền tối) |

## `board/` — lưới ảnh khi scroll thu nhỏ hero

- `1.webp` … `4.webp`, `5.jpg`, `6.webp`

## `projects/` — portfolio

Mỗi project một thư mục:

- `project-1/` → Lome  
- `project-2/` → Vana  
- `project-3/` → Nika  
- `project-4/` → Nari  

Trong mỗi thư mục:

- `cover.webp` — ảnh bìa card  
- `1.webp`, `2.webp`, `3.webp` — gallery trong modal  

## `clients/` — logo đối tác

- `1.svg` … `11.svg`

## `ui/` — icon (thường không cần đổi)

- `arrow-down.svg`, `arrow-right.svg`, `arrow-white.svg`, `close.svg`

## Gợi ý

- Hero / cover: ngang ~1600–2000px, WebP hoặc JPG  
- Giữ **tỷ lệ gần giống** ảnh cũ để layout ổn  
- Sau khi thay ảnh: refresh trình duyệt (Cmd+Shift+R)
